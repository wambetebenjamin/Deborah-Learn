## 12. Other findings that shaped the build

- No `package.json`, no build tooling, no framework. The Next.js application was scaffolded
  around the template's design language.
- The template is Bootstrap 4 based, with jQuery plugins (Owl Carousel, AOS, Stellar, Slick,
  Fancybox, Magnific Popup, MediaElement, Typed.js). These scripts are static only; the port
  reimplements the layout and effects with React, Tailwind CSS 4, Framer Motion and GSAP,
  because jQuery DOM plugins cannot be reused safely inside a React tree.
- CSS custom properties were the only design tokens. Colour, spacing, and type values were
  lifted from `css/style.css` and `scss/_site-base.scss` (the `#46ddb0` mint primary, the
  `#7971ea` purple accent, the `1.1rem` body size, the `1.7` line height, and the pill buttons).
- Two em dashes existed in the template titles (`OneSchool &mdash; Website by Colorlib`). Both
  were replaced with a comma, per the no em dash rule. No em dash exists anywhere else in the
  project.
