## Template assets

Files under `public/images/template/` and `public/fonts/` are reproduced unmodified from the
uploaded `oneschool-master.zip` (OneSchool by Colorlib, MIT licensed). The icon fonts Flaticon
and IcoMoon ship their own licence files in `public/fonts/`.

## If you switch to Pexels

The brief asked for Pexels imagery, and `next.config.ts` already allows
`images.pexels.com` in `images.remotePatterns`. The sandbox used for this build had no outbound
access to Pexels, so the photographs above were generated instead. To use Pexels photos:

1. Search https://www.pexels.com for the queries in the brief (for example "student laptop Africa").
2. Download the photos into `public/images/` using the same file names.
3. Add the photographer and photo URL to the table above, as the Pexels licence requires.
